# 简易命令行计算器

一个用**纯 C 语言**编写的命令行计算器，适合 C 语言入门学习和 Git 练习使用。

## 功能

- ➕ 加法、➖ 减法、✖️ 乘法、➗ 除法
- 取余运算（`a % b`）
- 幂运算（`a ^ b`，基于数学库 `pow`）
- 计算历史记录（最多保存 20 条，存满后自动丢弃最旧的）
- 除零检查、非法输入检查

## 编译与运行

```bash
# 编译（需要链接数学库 -lm，Linux/Mac 下必须，Windows 可省略）
gcc calculator.c -o calculator -lm

# 运行
./calculator        # Windows 下运行 calculator.exe
```

## 使用示例

```
========= 简易计算器 =========
  1. 加法 (a + b)
  2. 减法 (a - b)
  ...
请选择: 1
请输入两个数字（用空格分隔）: 3.5 2
结果: 5.5
```

## 涉及的 C 语言知识点

| 知识点 | 在代码中的位置 |
|--------|----------------|
| 函数封装 | `add()` / `sub()` / `mul()` 等运算函数 |
| switch-case | 菜单选择逻辑 |
| do-while 循环 | 主循环，直到用户输入 0 退出 |
| 二维数组 | `history[][]` 保存历史记录 |
| 字符串处理 | `snprintf` / `strcpy` 拼接算式 |
| 防御性编程 | 除零检查、`scanf` 返回值检查、清空输入缓冲区 |
